# Suran.Memory

分层记忆：把旧对话压成摘要留在原位置，超出容量自动归档到外存；可按关键词检索全部历史、取回原文，也能主动记录重要的事。

## 功能

- 压缩：旧的对话压成摘要，仍放在历史的原位置，保持时间连续
- 归档：上下文超出容量时，未钉住的条目移出上下文、原文存到外存
- 检索：按关键词搜全部历史，命中后取回原文
- 主动记录与遗忘，可按 id 精确操作
- 归纳：从新存档里提炼规律与信念，存成可检索的条目
- 检索会参考当时的心情重排，结果不足时换几种说法再搜
- 事实键：同一对象同一方面，新值自动顶掉旧值
- 星云：把记忆摊成一张星图，按主题成团、按心情着色
- 状态查询：库里多少条、多少条在上下文、多少条有原文
- 导出完整上下文，方便核对模型实际看到了什么
